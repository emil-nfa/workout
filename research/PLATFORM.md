# Platform checks (M1)

Checked 21/11/2026 against official sources. These decide what the app relies on.

| # | Question | Verdict | Sources | What the app does |
|---|---|---|---|---|
| P1 | Screen Wake Lock in Home Screen web apps | **Works from iOS/iPadOS 18.4** (WebKit fixed it for Home Screen web apps in Safari 18.4; Safari tabs had it since 16.4). Lock is released when the page is hidden. | [WebKit: Safari 18.4](https://webkit.org/blog/16574/webkit-features-in-safari-18-4/), [WebKit: Safari 16.4](https://webkit.org/blog/13966/webkit-ios-16-4-what-is-new/), [MDN Screen Wake Lock](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API), [caniuse](https://caniuse.com/wake-lock) | Request the lock when a workout or stretch starts, re-request on `visibilitychange`, release on finish. Setting in Me to turn it off. |
| P2 | `navigator.vibrate` on iOS | **Not supported** (Safari on iOS, all versions through 27.x). | [caniuse vibration](https://caniuse.com/vibration), [MDN vibrate](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/vibrate) | No vibration code path relied on. Feedback = beep, spoken cue, slow colour fill. Haptics wait for the v3 native shell. |
| P3 | `navigator.share({files})` with a .zip / .json | **Web Share is supported; whether a .zip is accepted is not documented.** MDN's list of usually shareable types has no zip or json, and says to always test with `navigator.canShare()`. Needs a user gesture. | [MDN share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share), [MDN canShare](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/canShare), [caniuse web-share](https://caniuse.com/web-share) | Backup button calls `canShare({files})` first. If false or if share throws (other than the user cancelling), fall back to a download link (`<a download>`), which iOS saves to Files. **To confirm on the user's iPhone** in the real-device check. |
| P4 | `navigator.storage.persist()` and eviction | Returns a boolean; WebKit grants it **by heuristics, one being "opened as a Home Screen web app"**. Eviction is per origin, least recently used, under quota or storage pressure or after a period without use (no day count given in this post). Persistent origins are excluded from eviction. | [WebKit: Updates to Storage Policy](https://webkit.org/blog/14403/updates-to-storage-policy/), [MDN persist](https://developer.mozilla.org/en-US/docs/Web/API/StorageManager/persist) | Call `persist()` on launch in standalone mode, show the result in Me → Storage. Backups stay the safety net either way. |
| P5 | Barlow Condensed tabular figures | **Has `tnum`**: checked in the shipped font file (fontsource 5.x, weight 600): digits map to `zero.tf` … `nine.tf`, all 475 units wide. Default digits are proportional, so `font-variant-numeric: tabular-nums` must be set. | Font file inspected with fontTools | One number font in both modes: Barlow Condensed with `tabular-nums`. IBM Plex Mono not needed. |

Note on the plan's "7-day cap": the WebKit storage-policy post gives no day count; the 7-day figure comes from the earlier ITP script-writable storage rule for Safari tabs. Home Screen web apps are the safer place either way, so the install-first rule stays.
